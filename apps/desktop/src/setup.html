            Set up an always-on server
            
On a Linux server with Docker, run this from a Rakazo checkout:

            
bash infra/compose/deploy-server.sh \
  --host app.example.com \
  --allow-signup owner@example.com \
  --build --prepare-only

            
Use your hostname and signup email. Configure email in the generated .env, then repeat without --prepare-only. Point DNS at the server and allow ports 80 and 443.
